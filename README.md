# sistema-gestion-socios-dar-es-dar
Materia: Modelado Orientado a Objetos

Descripción

Sistema de gestión de socios para la mutual Dar es Dar, desarrollado como trabajo práctico de la materia Modelado Orientado a Objetos.

El proyecto busca aplicar conceptos de programación orientada a objetos, relaciones entre clases, organización por capas y bases de datos.

Tecnologías

Python

MySQL

Git y GitHub

UML

Funcionalidades

Alta, consulta, modificación y baja de socios.

Registro de familiares.

Consulta de beneficios.

Solicitud y actualización de solicitudes.

Estructura

src/: código fuente.

database/: scripts SQL.

documentacion/: diagramas y descripción.

pruebas/: pruebas del sistema.

Estado

En desarrollo.
