# Sistema de Gestión de Socios – Dar es Dar

**Modelado Orientado a Objetos**

## Tecnologías

- Python
- MySQL
- Git y GitHub
- UML

## Funcionalidades

- Alta, consulta, modificación y baja de socios.
- Registro de familiares.
- Consulta de beneficios.
- Solicitud y actualización de solicitudes.

## Estructura

- `src/`: código fuente.
- `database/`: scripts SQL.
- `documentacion/`: diagramas y documentos.
- `pruebas/`: pruebas del sistema.
